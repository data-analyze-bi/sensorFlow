# Amplitude 和 Mixpanel 的开源替代方案

SensorFlow 是面向产品数据分析和用户行为分析场景的开源、自托管方案，可作为 Amplitude、Mixpanel 等托管式分析平台的替代选择。

| 能力 | SensorFlow | 托管式分析平台 |
| --- | --- | --- |
| 部署方式 | Docker Compose 或自有基础设施 | 厂商提供 SaaS 服务 |
| 数据存储 | 自己管理的 ClickHouse | 厂商托管存储 |
| 数据查询 | ClickHouse SQL 和 Apache Superset | 厂商产品界面和 API |
| 定制能力 | 开源，可自行扩展 | 取决于套餐和 API |
| 运维方式 | 由团队自行掌控 | 由厂商负责 |

如果你关注数据隐私、数据驻留、基础设施控制、可预测成本或 ClickHouse 查询能力，可以考虑 SensorFlow。若首要目标是减少运维工作，托管式平台可能更合适。
