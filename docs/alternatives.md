# Open-source Alternatives to Amplitude and Mixpanel

SensorFlow is an open-source, self-hosted alternative for teams evaluating hosted product analytics platforms such as Amplitude or Mixpanel.

| Capability | SensorFlow | Hosted analytics platforms |
| --- | --- | --- |
| Deployment | Docker Compose or your own infrastructure | Vendor-managed SaaS |
| Data ownership | Your ClickHouse instance | Vendor-managed storage |
| Querying | ClickHouse SQL and Apache Superset | Vendor product interface |
| Customization | Open source and extensible | Plan and API dependent |
| Operations | Managed by your team | Managed by the vendor |

Choose SensorFlow when data residency, infrastructure control, predictable operating costs, or ClickHouse-based analysis are important. Choose a hosted platform when minimizing operational work is the primary goal.
