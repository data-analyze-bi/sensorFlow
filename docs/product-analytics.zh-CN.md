# 埋点分析、产品数据分析与用户行为埋点

SensorFlow 为 Web、Android、iOS、小程序和服务端应用提供自托管产品分析能力。已有神策 SDK 应用可以直接将事件发送到 SensorFlow 接收接口，无需开发新的客户端 SDK。

## 数据链路

1. 应用通过平台 SDK 记录用户事件。
2. SDK 将事件发送到 SensorFlow 接收接口。
3. Go 服务校验并处理事件数据。
4. ClickHouse 保存事件和用户数据。
5. Apache Superset 展示产品指标和用户行为分析结果。

常见分析包括事件量、活跃设备、转化漏斗、留存分析基础数据和热门事件。你可以根据业务事件模型调整 SQL 和数据看板。
